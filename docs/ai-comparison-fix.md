# 운영 AI 상품 비교 복구 · 2026-09-06

- 운영 origin으로 비교 API를 호출하면 `403 ORIGIN_NOT_ALLOWED`가 반환되었고, origin 없이 같은 인증 계정·상품을 요청하면 Gemini 비교가 성공했다. 배포 함수와 로컬 코드는 동일했다.
- 브라우저의 OPTIONS 사전 요청 차단은 클라이언트의 `FunctionsFetchError`로 이어져 “AI 서비스 응답이 원활하지 않아요”로 표시된다.
- 운영 origin을 기본 허용 목록에 넣고 기존 설정의 추가 origin은 유지했다. 다른 Vercel 도메인과 유사 도메인을 허용하지 않는 회귀 테스트를 추가했다.
- 복구 검증 중 `INVALID_RESPONSE`도 한 번 관찰했다. 응답 잘림 가능성을 줄이도록 비교 출력 한도를 768에서 1536 토큰으로 확장했다. 해당 오류의 세부 원인은 확정하지 않았으며 기존 결과 검증은 유지한다.
- Supabase `ai-insights` 함수에 배포한 후 운영 origin의 OPTIONS 204와 서로 다른 2개·3개 상품 조합의 실제 Gemini 비교 응답을 확인했다.
- 전체 테스트 176 통과·2 skip, lint 오류 없음(기존 경고 6개), 빌드 성공(기존 번들 크기 경고). 출력 한도 보완 후 AI 관련 23개 테스트를 다시 통과했다.
