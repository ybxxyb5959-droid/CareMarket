# 리뷰 신고 및 관리자 처리

구현: 리뷰 우측 신고 → 로그인 회원의 사유/상세 접수 → 관리자 리뷰 관리의 접수 대기/삭제 완료/리뷰 유지 필터. 관리자 삭제는 기존 reviews.deleted_at을 사용해 공개 조회에서 제외하며 신고 기록을 보관한다. 같은 리뷰에 접수된 미처리 신고는 삭제 시 함께 처리한다. 기본 표시 후기는 별도 삭제 목록으로 공개 화면에서 제외한다.

대시보드: 접수 대기 수, 전체 신고 수, 최근 5건, 리뷰 관리 이동. 열린 대시보드에서는 15초 간격 및 창 포커스 복귀 시 새로 조회한다. 조회 실패는 오류로 표시한다.

## DB 적용

2026-09-08 후속 요청으로 운영 반영 완료. Supabase 프로젝트 owxgtzepynkwdixmwhim에 20260908000200 및 20260908000300의 SQL을 편집기로 수동 적용했다. 이미 반영된 SQL을 재실행하지 않는다. migration 이력은 별도 기록하지 않았다. 기존 수동 적용 이력을 함께 검토한 후 추후 이력 동기화가 필요하다. 전체 db push로 과거 마이그레이션을 재실행하지 않는다.

신규 테이블: review_reports, deleted_sample_reviews. 신규 RPC: submit_review_report, get_admin_review_reports, resolve_review_report. 회원은 직접 신고 테이블을 조회/수정할 수 없으며, 관리자 목록과 처리는 서버 is_admin() 검사로 보호한다. 동일 회원/리뷰 신고는 unique 제약으로 한 번만 접수된다.

기본 표시 후기의 신고 본문은 신고자가 전달한 화면 내용이며, 구매 확인 후기의 본문은 서버의 reviews 원문에서 가져온다. 관리 화면에 후기 유형을 구분하여 표시한다.
